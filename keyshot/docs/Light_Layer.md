# 灯光层

该板块是新增命令，支持的版本：

**该板块的目的：**
单独对场景中某一个或多个部件进行独立打光。该板块支持的灯光有：环境，以及软件自带的各类区域光，聚光灯，点光等物体。

```
位置: 场景 > 模型 > 属性 > 灯光层，（图中黄色框中的命令可以调出灯光层板块的详细窗口。）
```
